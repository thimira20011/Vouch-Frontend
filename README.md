# Vouch Frontend

Initial React + Vite project for Vouch — Considered Connections.

## Development

Requires Node.js 22 or later.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Structure

- `src/main.jsx`: React entry point
- `src/App.jsx`: starter screen; full Figma screens are not implemented yet
- `src/styles/tokens.css`: initial Vouch design tokens
- `src/styles/index.css`: global and starter styles

The design specifies Inter and Cormorant Garamond. Font files are not bundled yet; system and Georgia fallbacks are used for this initial scaffold.

Design reference: https://www.figma.com/design/ZBzLM8HfRsC5KGH59o3Dpo/Vouch?node-id=0-1
